🛡 DPI Engine v3.0

Multi-threaded Deep Packet Inspection Engine with real-time traffic analysis, anomaly detection, ML-based app classification, and flow replay forensics.

🔬 Deep Packet Inspection ✅ Multi-threaded C++17 🚨 Anomaly Detection 🧠 ML Classification 🔄 Flow Replay Forensic Standalone Mode (1,980 Packets)
⭐ GitHub Repository
🔬

Deep Packet Inspection

Parses Ethernet, IPv4, TCP, UDP headers. Extracts SNI from TLS Client Hello for encrypted traffic classification. Identifies 20+ applications.

⚡

Multi-threaded Pipeline

Reader → Load Balancer → Fast Path Processors → Output. Lock-free queues with thread-safe flow table for high-throughput packet processing.

🚨

Anomaly Detection

Detects port scans, DDoS patterns, SYN floods, and connection bursts using statistical baseline profiling and sliding window analysis.

🧠

ML App Classification

Uses flow features — packet size distribution, inter-arrival times, byte entropy — to classify encrypted traffic where SNI is absent.

🔄

Flow Replay & Forensics

Reconstruct individual TCP/UDP flows. Inspect packets with hex dumps. Export per-flow PCAP slices for incident investigation.

🔒

Rule-Based Blocking

Block by IP, application, domain, or port. Persistent rule storage. Integrates with the fast-path for wire-speed enforcement.

🔨 Build & Run

How to compile the C++ engine and run the web dashboard

1. Compile the DPI Engine

$ g++ -std=c++17 -pthread -O2 -o dpi_engine \ src/dpi_mt.cpp src/packet_parser.cpp src/pcap_reader.cpp \ src/sni_extractor.cpp src/fast_path.cpp src/rule_manager.cpp \ src/types.cpp -Iinclude

2. Run the Engine

$ ./dpi_engine test_dpi.pcap

3. Start the Dashboard

$ cd dashboard $ pip install flask flask-cors $ python3 server.py # Open http://localhost:8080

4. Generate Test Data

$ python3 generate_test_pcap.py
